# AquaCircle Biorefinery

**Turning aquaculture waste into circular blue value.**

AquaCircle Biorefinery is an early-stage venture developing compact modular bioprocessing units that convert aquaculture and seafood by-products — shrimp shells, fish offal, and seafood trimmings — into high-value biomaterials including **chitosan** and **bioactive peptides**.

> 🏆 **Finalist — Ocean Community Challenge 2026** | Blue Readiness Pathway

---

## The Problem

Aquaculture and seafood processing generate large volumes of organic by-products that are routinely underused, poorly managed, or disposed of at low value. For small and medium coastal producers, waste becomes a recurring cost rather than a source of income:

- **Disposal costs** — Producers pay to remove shells, offal, and trimmings with no return
- **Lost biomaterial value** — High-value chitosan and peptides remain locked in waste streams
- **Environmental burden** — Uneven waste handling raises emissions, nutrient loads, and disposal risk for coastal communities

---

## Our Solution

AquaCircle brings **decentralized blue bioprocessing** directly to farms, processors, and coastal production hubs. Our compact modular units are designed to operate at scale for small and medium producers — without requiring large industrial infrastructure.

**Designed for:**
- Fish farms and hatcheries
- Seafood processors
- Producer cooperatives
- Community-level coastal processing hubs

---

## Technology

The AquaCircle system integrates modular hardware, IoT monitoring, and AI-assisted process optimization to deliver consistent, reliable outputs:

| Component | Description |
|---|---|
| **Modular Hardware** | Compact units built for coastal sites and small farms where space and flexibility matter |
| **IoT Process Monitoring** | Real-time sensor tracking of temperature, pH, timing, and yield |
| **AI-Assisted Monitoring** | Designed to support future optimization and improve consistency over time |
| **Standardized Output Quality** | Reliable chitosan and peptide yield that partners can use with confidence |

## Impact

AquaCircle's approach is designed to support a **circular value chain** for coastal aquaculture:

- ♻️ **Waste valorization** — Organic by-products become useful biomaterials
- 💰 **New income streams** — Small operators gain revenue from chitosan, peptides, and circular product flows
- 🌊 **Reduced environmental burden** — Local processing lowers waste transport and improves coastal compliance
- 🐟 **Sustainable aquaculture alignment** — Turning waste into measurable circular value supports regenerative sector goals

## Repository

This repository contains the source code for the AquaCircle Biorefinery public-facing website — a single-page static site built with vanilla HTML and CSS.

### Stack

- **HTML5** — Semantic, accessible markup
- **Vanilla CSS** — Custom design system with CSS variables, glassmorphism, and scroll-reveal animations
- **Google Fonts** — Outfit (headings) + Inter (body)
- **No frameworks, no dependencies** — Pure static site, deployable anywhere

### Running Locally

```bash
# Python (built-in, no install needed)
python -m http.server 3000
# Then open http://localhost:3000
```

### Deployment

The site can be deployed to any static host. For GitHub Pages:

1. Go to **Settings → Pages**
2. Set source to **main branch → / (root)**
3. Site will be live at `https://temabef.github.io/aquacircle/`
